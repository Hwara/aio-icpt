# ADR 0002: Modbus TCP 수직 슬라이스를 먼저 구현

## 상태

승인됨

## 배경

전체 프로젝트는 여러 프로토콜, 로그, 저장소, Export, 자동화, 향후 데이터베이스 선택지를 포함한다. 모든 기반을 먼저 구현하면 피드백이 늦어지고, 실제 동작으로 검증되지 않은 추상 구조를 만들 가능성이 커진다.

## 결정

하나의 수직 슬라이스부터 구현한다. 첫 슬라이스는 UI에서 시작해 Core, protocol session, SQLite까지 이어지는 Modbus TCP Read Holding Registers 흐름이다.

## 결과와 tradeoff

- 아키텍처 결정을 실제 동작으로 일찍 검증할 수 있다.
- 미뤄진 기능은 문서에 남기되 첫 구현을 불필요하게 복잡하게 만들지 않는다.
- 문서는 여러 미완성 계층보다 하나의 완성된 호출 흐름을 중심으로 설명할 수 있다.
